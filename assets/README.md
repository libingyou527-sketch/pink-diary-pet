# Assets

This repository does **not** ship a Live2D model or WebM animation.

The original private setup used a model from the Steam Workshop work of
**RelySeven**. That model is not MIT licensed and must not be redistributed
with this code repository or used commercially without permission.

To use your own model:

1. Place the model under `assets/model/` locally (ignored by Git).
2. Point dsh-pet at it according to dsh-pet's model configuration.
3. Keep your own asset license in `assets/model/LICENSE` if applicable.

The code is MIT licensed; the model is not.
